## 槪述

## 文賦與詩的分別

- 詩的文字結構比較嚴格，如近體詩，字句的數目是固定的（絕律詩），至少是有規則的（排律）
- 因爲要押韻，詩句的分界也很容易辨識
- 賦可以押韻，但句中字數不固定，押韻也不嚴格
- 文賦中，句與句之間沒有明確的界限，不同版本可以有不同的斷句
- 文字內容的分段也可以因版本不同而有差異
- 處理詩的方式不一定適用於文賦

## 順序碼

- 把一篇文字所有的標點符號都去掉
- 爲這段文字編碼，從 1 開始，每個字一個不同的碼
<pre>
$txt = '臣甫言臣生長陛下淳樸';
$txt_tree = array();

for( $i = 0; $i < mb_strlen( $txt ); $i++ )
{
	$碼 = $i + 1;
	$txt_tree[ "$碼" ] = mb_substr( $txt, $i, 1 );
}
print_r( $txt_tree );
</pre>

結果：
<pre>
Array
(
    [1] => 臣
    [2] => 甫
    [3] => 言
    [4] => 臣
    [5] => 生
    [6] => 長
    [7] => 陛
    [8] => 下
    [9] => 淳
    [10] => 樸
)
</pre>

## 文字的增減、改變

這種單一層的樹結構容許通過簡單的轉化，進行文字的增減、改變：

<pre>
$txt_tree[ 2 ] = '';
$txt_tree[ 3 ] = '云';
// insert
$txt_tree[ 4 ] = $txt_tree[ 4 ] . '不得';
print_r( implode( $txt_tree ) );
</pre>

- 結果：
<pre>臣云臣不得生長陛下淳樸</pre>
- 如有需要，新生成的文字可以重新編順序碼
- 這種簡單的文字修改，可以通過現有的處理異文的機制來進行

## 樹骨架

- 樹骨架是一種對某個樹結構的高一層次的說明
- 樹結構例子：
<pre>
    [6124] => Array
        (
            [1] => Array
                (
                    [1] => Array
                        (
                            [1] => 
                            [2] => 
                            [3] => 
                        )

                    [2] => Array
                        (
                            [1] => 
                            [2] => 
                            [3] => 
                            [4] => 
                            [5] => 
						...
            [2] => Array
                (
                    [1] => Array
                        (
                            [1] => 
                            [2] => 
                        )

                    [2] => Array
                        (
                            [1] => 
                            [2] => 
                            [3] => 
                            [4] => 
                        )
						...
</pre>

- 這個樹結構可以用段、句、字三層的結構來說明：
  - 此文有兩段
  - 第一段十七句，第二段二十七句
  - 第一段第一句三個字，第二句九個字
- 相對應的樹骨架：
<pre>
$樹骨架 => array( 
	array( 3,9,5,7,9,7,5,7,5,8,4,4,4,4,4,4,10 ),
	array( 2,4,4,8,8,6,4,4,4,4,4,6,6,5,10,6,5,4,3,
	4,4,8,4,10,6,4,2 ) ),
</pre>
- 這種樹骨架可以從帶句號的文字直接生成
- 利用樹骨架，可以生成一棵不帶任何文字的空樹

## 樹骨架的轉化

- 用簡單的陣列方法，可以把一個樹骨架轉化成另一個樹骨架
- 例子：
<pre>
$樹骨架 = array(
	array( 3, 7, 9, 2 ),
	array( 4, 4, 8 ),
	array( 2, 5 ),
	array( 6, 9, 8 )
);
// 段：例一
// 去掉最後一段
$last_parag = array_pop( $樹骨架 ); // 6,9,8
// 去掉第一段
$first_parag = array_shift( $樹骨架 ); // 3,7,9,2
// 重新組合
$樹骨架 = array_merge(
	array_slice( $樹骨架, 0, 1 ), // 4,4,8
	array( $last_parag, $first_parag ),
	array_slice( $樹骨架, 1 )
);

// 段：例二
// 去掉中間的一段
$樹骨架 = array_merge(
	array_slice( $樹骨架, 0, 2 ),
	array_slice( $樹骨架, 3, 1 ),
);

// 句
// 去掉第一段中間的一句
$樹骨架[ 0 ] = array_merge(
	array_splice( $樹骨架[ 0 ], 0, 1 ),
	array_splice( $樹骨架[ 0 ], 1 ) );

// 字
// 隨意修改字數
</pre>

## 分派文字

- 修改後的文字，和由樹骨架生成的空樹，如果字數相等，則文字可以被分派到樹中的末端節點
- PHP code:
<pre>
function recusively_fill_data(
	array &$tree, string $path ) : void
{
	global $text;
	global $index;
	global $paths;
	global $map;
	$keys = array_keys( $tree );
	
	foreach( $keys as $key )
	{
		$temp = ltrim( $path, ',' );
		
		if( is_array( $tree[ $key ] ) )
		{
			recusively_fill_data( $tree[ $key ], 
				$temp . ',' . $key );
		}
		else
		{
			$tree[ $key ] = mb_substr( $text, $index, 1 );
			$index++;
			$map[ ltrim( $path, ',' ) . ',' . $key ] = 
				$index;
		}
	}
}
</pre>

## 索引

- recusively_fill_data 同時生成一個路徑=>順序碼的對照表
- 通過順序碼=>文字的對照表，可以生成路徑=>文字的對照表
- 一篇文、賦中的文字，同時擁有兩個碼：
  - 順序碼
  - 樹路勁
