## 文賦與詩的分別

- 詩的文字結構比較嚴格，如近體詩，字句的數目是固定的（絕律詩），至少是有規則的（排律）
- 因爲要押韻，詩句的分界也很容易辨識
- 賦可以押韻，但句中字數不固定，押韻也不嚴格
- 文賦中，句與句之間沒有明確的界限，不同版本可以有不同的斷句
- 文字內容的分段也可以因版本不同而有差異
- 處理詩的方式不一定適用於文賦

## 樹骨架的轉化

- 用簡單的陣列方法，可以把一個樹骨架轉化成另一個樹骨架
- 以陣列方法改變段、行、句
- 陣列方法包括 `array_pop`、`array_shift`、`array_slice`、`array_splice`、`array_merge`
- 陣列中的數字可以按需要修改

## 索引

- 「空樹末端節點塡文字」同時生成一個路徑=>順序碼的對照表
- 通過順序碼=>文字的對照表，可以生成路徑=>文字的對照表
- 一篇文、賦中的文字，同時擁有兩個碼：
  - 順序碼
  - 樹路徑

## 文賦與詩處理方法的差異

- 處理詩時，由於句數、字數相對穩定，可以用同一棵正文樹來生成不同的版本
- 修改文字可以與添加注釋、校記等資料同時進行
- 文賦則不然，不同版本可以有不同的分句、分段，甚至容許字數不同
- 修改文字必須在生成樹結構之前完成
- 不同版本可以有不同的樹結構
- 處理文賦的觀念可以應用到已經生成的詩正文樹上
- 例子：爲仇兆鰲《杜詩詳註·北征》分段（八段），見<a href="https://github.com/wingmingchan64/CanonicalTextTrees/blob/main/corpus/dufu/%E6%9D%9C%E8%A9%A9%E8%A9%B3%E8%A8%BB/views/0145%E5%88%86%E6%AE%B5.json">0145分段.json</a>

## 文字塊、樹骨架的定位

- 語義、功能說名：文字塊是字/詞層的，樹骨架是大於字/詞的
- 文字塊、樹骨架二元分割，也適用於詩
- 樹骨架是最底層的結構，空樹、正文樹，是衍生物

## 文字塊、樹骨架的延申

- 處理有現代標點符號的文字

<pre>王觀國《學林》：子美詩，蓋用道書中陶隱居《登真訣》，有乾石青精䭀飯法。……

王觀國學林子美詩蓋用道書中陶隱居登真訣有乾石青精䭀飯法

array( 
	array( [ 'zzmh',3,'yzmh' ], [ 'zsmh',2,'ysmh','maoh' ], [ 3,'douh' ], [ 8 ], [ 'zsmh',3,'ysmh','douh' ], [ 8,'juh' ], ... )
）

zzmh：左專名號
yzmh：右專名號
zsmh：左書名號
ysmh：右書名號
maoh：冒號
douh：逗號
juh：句號
</pre>	
	
- 從基準正文開始，可以用程式生成文字塊、樹骨架、空樹、正文樹等等
- 同樣的方法可以用來儲存杜著述
- 適用於英語、法語、德語等外語
