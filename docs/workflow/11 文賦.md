# 11 文賦

Status: Draft

---

## 槪述

本文介紹如何處理杜甫文賦。

---

## 文賦與詩的分別

- 詩的文字結構比較嚴格，如近體詩，字句的數目是固定的（絕律詩），至少是有規則的（排律）
- 因爲要押韻，詩句的分界也很容易辨識
- 賦可以押韻，但句中字數不固定，押韻也不嚴格
- 文賦中，句與句之間沒有明確的界限，不同版本可以有不同的斷句
- 文字內容的分段也可以因版本不同而有差異
- 處理詩的方式不一定適用於文賦

## 順序碼

- 把一篇文字所有的標點符號都去掉
- 爲這段文字編碼，從 1 開始，每個字一個不同的碼
<pre>
$txt = '臣甫言臣生長陛下淳樸';
$txt_tree = array();

for( $i = 0; $i < mb_strlen( $txt ); $i++ )
{
	$碼 = $i + 1;
	$txt_tree[ "$碼" ] = mb_substr( $txt, $i, 1 );
}
print_r( $txt_tree );
</pre>

結果：
<pre>
Array
(
    [1] => 臣
    [2] => 甫
    [3] => 言
    [4] => 臣
    [5] => 生
    [6] => 長
    [7] => 陛
    [8] => 下
    [9] => 淳
    [10] => 樸
)
</pre>

## 文字的增減、改變

這種單一層的樹結構容許文字的增減、改變：

<pre>
$txt_tree[ 2 ] = '';
$txt_tree[ 3 ] = '云';
// insert
$txt_tree[ 4 ] = $txt_tree[ 4 ] . '不得';
print_r( implode( $txt_tree ) );
</pre>

結果：
<pre>臣云臣不得生長陛下淳樸</pre>
