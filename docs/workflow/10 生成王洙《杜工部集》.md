# 10 生成王洙《杜工部集》

Status: Draft

---

## 槪述

本文介紹如何生成王洙《杜工部集》。此處所提及的所有生成的文檔，可見於`CanonicalTextTrees\corpus\dufu\杜工部集\`。

---

## 於目錄中增加條目

在`目錄.txt`中增加：

<pre>
醉時歌 0409,0017,125
</pre>

又在`版詩碼_默詩碼.json`中增加：

<pre>
"0017":"0409"
</pre>

此文檔在`目錄.txt`完成後可用程式生成。

---

## 手編`canonical_text\0017.txt`

於`canonical_text\0017.txt`中列出《杜工部集》的異文（與默認版本不同之處）：

<pre>
醉時歌

一云。所談或屈宋。
坎
𩯭
覔
簷
盗
盃
</pre>

---

## 生成正文樹

以下程式生成`trees\0017.json`:

<pre>
php H:\github\CanonicalTextTrees\tools\php\bin\執行路徑程式.php WANGZHU
</pre>

`trees\0017.json`的內容：

<pre>
{
    "0017": {
        "篇名": "醉時歌",
        "1": {
            "3": "一云。所談或屈宋。",
            "4": "坎",
            "5": "𩯭",
            "6": "覔",
            "7": "簷",
            "8": "盗",
            "9": "盃"
        }
    }
}
</pre>

在此樹中，可用像`WANGZHU,0017,1,6`的路徑提取相應文字（`覔`）。

---

## 手編`metadata\0017\異文.txt`

在`metadata\0017\異文.txt`加入後設資料標記：

<pre>
{"scope":"宋","src_path":"WANGZHU,0017,1,3","op":"insert"}
{"scope":"轗","src_path":"WANGZHU,0017,1,4"}
{"scope":"鬢","src_path":"WANGZHU,0017,1,5"}
{"scope":"覓","src_path":"WANGZHU,0017,1,6"}
{"scope":"檐","src_path":"WANGZHU,0017,1,7"}
{"scope":"盜","src_path":"WANGZHU,0017,1,8"}
{"scope":"杯","src_path":"WANGZHU,0017,1,9"}
</pre>

"scope"的値如果是詩文片段，每個詩文片段在此默認文檔中只能出現一次。

---

## 生成後設資料指令樹

以下程式生成`metadata\trees\0017.json`

<pre>
php H:\github\CanonicalTextTrees\tools\php\bin\王洙\生成後設資料樹.php
</pre>

`metadata\trees\0017.json`的內容：

<pre>
{
    "WANGZHU": {
        "0017": {
            "異文": {
                "0409,5,2,7": {
                    "WANGZHU,0017,1,3": "insert"
