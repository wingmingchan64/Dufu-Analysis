# Dealing With Annotations (注釋) Etc.

## 杜著述s

- 杜著述s with annotations, comments (評論), etc., can be treated in a way similar to that of variants (異文)
- Whatever not found in 默認版本 can be treated as (B - A)
- 默認版本 can be treated as a hierarchical tree structure 
- Additional information from (B - A) can stored in the hierarchical tree, using additional nodes

---

## Generating Version B

- Using A as the starting point, only (B - A) is needed
- (B - A), meaning any texts that is not authored by 杜甫, 
including annotations, comments, and so on, can be treated as additions to A
- The hierarchical tree structure can be used
- There is no need of storing B separately

---

## Listing More Than One 杜著述

- It is possible to attach texts of any number of 杜著述s to the same tree based on A
