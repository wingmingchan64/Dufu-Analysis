# Trees

## Definitions

- Rooted Tree: A connected, acyclic structure consisting of nodes and edges, with one designated node called the root
- Root: The designated node that has no parent
- Parent & Child: Two directly connected nodes, where the node closer to the root is the parent and the other is its child
- Leaf: A node that has no children
- Internal Node: Any node that has at least one child (not a leaf)
- Edge: A connection between two nodes
- Depth: The number of edges from the root to a specific node
- Height: The maximum number of edges from a node to any of its descendant leaves

---

## Key Properties

- Edge Count: A tree with N nodes always has exactly N - 1 edges
- Unique Path: There is exactly one path between any two nodes in a tree
- Acyclic: A tree contains no cycles
- Connectedness: Every node is reachable from every other node

---

## Ordered Trees

- Ordered Tree: A rooted tree in which the children of each node have a specified order
