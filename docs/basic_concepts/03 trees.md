# Trees (Gemini)

## Definitions

- A tree is a non-linear hierarchical data structure made of nodes connected by edges, with no loops or cycles
- Root: The topmost node in a tree that has no parent
- Parent & Child: A node that points to a lower node is the parent; the lower node is the child
- Leaf: A node that has no children
- Internal Node: Any node that has at least one child (not a leaf)
- Edge: The connection link between a parent and a child node
- Depth: The distance (number of edges) from the root to a specific node
- Height: The longest path from a node down to a leaf

---

## Key Properties

- Edge Count: A tree with N nodes always has exactly N - 1 edges
- Unique Path: There is one and only one path between any two nodes in a tree
- Acyclic: Trees cannot contain cycles or loops
