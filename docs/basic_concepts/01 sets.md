# Sets (Gemini)

## Introduction

- The current framework is designed and built upon concepts related to set and tree theories
- To understand how the framework processes texts of various languages, set theory is a good starting point

---

## Definition Of A Set

- A set is a well-defined collection of distinct objects, called elements

---

## Related Operations

- Element of a ∈ A: An object belonging to a set is an element
- Union (A ∪ B): Combines all unique elements from both A and B
- Intersection (A ∩ B): Contains only the elements that appear in both A and B
- Subset (A ⊆ B): Every element of set A is also an element of set B
- Difference (A - B): All elements of set A that are not elements of set B
