## Definition of a Set

- A set is a well-defined collection of distinct objects, called elements

---

## Related Operations and Relations

- Membership (a ∈ A): Indicates that a is an element of set A
- Union (A ∪ B): Contains all elements belonging to A or B, or both
- Intersection (A ∩ B): Contains all elements belonging to both A and B
- Subset (A ⊆ B): Indicates that every element of A is also an element of B
- Difference (A ∖ B): Contains all elements of A that do not belong to B
