# Order and Ordered Sets

## Ordered N-Tuple

- Ordered n-tuple (a<sub>1</sub>, a<sub>2</sub>, ..., a<sub>n</sub>): An ordered sequence of n elements
- The position of each element matters, and elements may be repeated

---

## Partial Orders

A binary relation ≤ on a set is a partial order if it satisfies:

- Reflexivity: Every element relates to itself (a ≤ a)
- Antisymmetry: If (a ≤ b) and (b ≤ a), then (a = b)
- Transitivity: If (a ≤ b) and (b ≤ c), then (a ≤ c)

A set equipped with a partial order is called a partially ordered set (poset).

---

## Total Orders

A partial order is a total order if it also satisfies:

- Totality: For any two elements a and b, either a ≤ b or b ≤ a

A set equipped with a total order is called a totally ordered set.
