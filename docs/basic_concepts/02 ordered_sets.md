# Ordered Sets (Gemini)

## Definition Of An Ordered n-Tuple

- Ordered n-tuple (a<sub>1</sub>, a<sub>2</sub>, ..., a<sub>n</sub>): An ordered sequence of n elements 

---

## The Relation ≤

- Reflexivity: Every element relates to itself (a ≤ a)
- Antisymmetry: If (a ≤ b) and (b ≤ a), then (a = b)
- Transitivity: If (a ≤ b) and (b ≤ c), then (a ≤ c)
